# 工具怎么选

在仓库根目录运行；先按目的选择入口，参数用 --help 查看。

| 要查什么 | 从这里开始 |
|---|---|
| 运行仿真或现场任务 | [run/](run/index.md) |
| 查看、回放、录像与截图 | [viewers/](viewers/index.md) |
| 环境、规划、碰撞和记录排查 | [diagnostics/](diagnostics/index.md) |
| 微波炉 Knowledge 调参 | [view_microwave_knowledge.py](editors/view_microwave_knowledge.py) |
| 通用抓取参数调整 | [view_grasp_knowledge.py](editors/view_grasp_knowledge.py)、[tune_grasp_profile.py](editors/tune_grasp_profile.py) |
| 场景抓取调整 | [tune_scene_grasp.py](editors/tune_scene_grasp.py) |
| 编辑物体 Concept | [edit_concept.py](editors/edit_concept.py) |
| 相机标定操作 | [README.md](../gene_agent/perception_modules/camera/calibration/README.md) |

具体操作示例见 [用户文档](../docs/user/index.md)。工具的内部辅助函数和旧专用脚本不逐项罗列。
