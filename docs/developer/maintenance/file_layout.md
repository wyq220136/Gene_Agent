# 文件与导航的维护边界

索引是帮助选择工作入口的地图，不是每个目录或文件必须配备的清单。

| 范围 | 保留方式 |
|---|---|
| 普通代码 | 只留 gene_agent/index.md 说明模块职责与主要入口；复用已有 README，具体调用链查源码 |
| 工具命令 | 按运行、查看、诊断目的选择；内部辅助文件不逐项登记 |
| 自动回归 | tests/index.md 按改动模块选测试；只有复杂专项和环境前提值得单独说明 |
| 长期文档 | 用户/开发者各一份目录，按问题选读；不强制逐层 index |
| 运行配置 | 文件名难以体现语义，保留消费者、用途和单位说明；少量配置并入总清单 |
| 资产与环境 | 按完整包说明，复用仓库入口和环境指南，不重复列目录树 |

- 只有几行、一两条记录或纯转链的索引并入上级；不靠模板文字凑篇幅，也不把缺索引当作删除代码/原始数据的理由。
- 仅保留明确有当前用途的内容。新入口/职责变化时才更新导航，普通实现变动无需逐文件改索引。
- 长期操作说明放 docs/user，接口与必要决策依据放 docs/developer；临时说明放 docs/tmp，不跟踪。
- 临时实验的脚本、配置和输出放 runs/tmp/<专题>/<本轮>/，可删除；有用的实验在相应本地说明中记录用途与复现入口。runs 数据及本地索引均不跟踪。
- 已淘汰的代码、配置与历史材料放 archive，不跟踪。正式配置记录消费者、来源、单位及覆盖关系，现场副本放忽略的 local，保留示例。
- 索引只引用正式入口和可分发说明；必要结论不能只存在于临时报告中。
- 整理导航时更新旧链接；不移动实现、改参数、删证据或顺手提交其他 Agent 的改动。改动实现时才运行相应行为回归，文档导航整理用链接、覆盖与内容哈希核验。
