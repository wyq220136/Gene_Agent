# 从仿真迁移到真机

## 何时读取与输入

仿真中所需动作和任务逻辑已验证，准备现场调试时读取。输入为仿真版本与证据、设备配置、当前标定、真实观测及任务参数。仿真成功不是发令授权；真机运动须单独授权与安全验收。

## 执行

1. 核对机器人/夹爪、关节顺序、SDK base、URDF、flange/TCP 及开合/抓力映射；更换硬件先看[迁移说明](robot_and_gripper.md)。标定按[相机标定入口](../../gene_agent/perception_modules/camera/calibration/README.md)操作。
2. 检查感知误差、相机可见性、mesh 尺度及 frame。观测保留来源、时间与坐标，过期或未验证 frame 的离线 pose 不能当实时状态。用把手估计物体时，开门后的把手运动不能误当作柜体运动。
3. 优先复用 Knowledge / Skill / Task 的操作逻辑，由真实观测和设备适配提供输入输出。仿真和真机可有不同速度、抓取深度、摩擦及感知参数，显式记录，不能为了共用而硬凑同一组数值。
4. 先做现场只规划检查，再在授权下逐 Skill / sub-task 低速执行，最后连续 Task。每段读取实测终态，遇到失败保留证据，不自动跳过或擅自回 home。
5. 真机未必能直接测到仿真接触力或任务判定所需的全部状态；明确可用传感、代理观测、人工检查和未知项，不虚构接触或成功。
6. 真机发现的问题若涉及共享操作逻辑，修改后回仿真做回归；现场感知与物理差异仍需重新验证。

## 交付与完成条件

交付现场有效参数、标定与感知来源、每段执行结果、失败恢复和未验证范围。真机成功率与仿真成功率分开统计，不把辅助夹持作为硬件能力。

设备适配以[真机代码说明](../../gene_agent/realworld/README.md)为入口；微波炉以[真机子任务说明](../user/microwave/realworld_microwave_entry.md)为入口，清扫以[真机执行说明](../user/sweep/sweep_realworld_execution.md)为入口。这些是不同任务的现有接线，不表示任意新任务自动获得真机支持，也不表示三后端已经共用完整执行循环。

## 失败处理

先区分观测错误、坐标错误、计划错误和硬件执行差异。对照[人类经验](../../human_experience.md)检查直接原因与根本原因；现场重要安全或任务语义决策请用户参与，不能以自主调试为由越过真机授权。
